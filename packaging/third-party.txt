# The bundled components: fetched and checksummed when the package is
# built (see .github/workflows/build.yml and packaging/appimage/build.sh).
#
# Each line: name url sha256 [more urls...]
# The first url that downloads AND matches the sha256 wins: later urls are
# fallbacks (our mirror on the 'thirdparty' release) for the day an
# upstream moves or disappears. The sha256 is the gate: an upstream update
# never enters a build silently — bump it deliberately after testing, and
# refresh the mirror (packaging/mirror.yml).
#
# Upstream's "latest" links live in packaging/upstream-watch.txt, checked
# weekly by .github/workflows/watch-upstream.yml.
